# Sources and status (2026-11-25)
- Recovered local V0.2 ZIP: countryinfo, pycountry, Babel and manual additions as documented by its LEGGIMI. Re-encoded factual country codes, capitals, area and approximate camera coordinates in src/countries.mjs. Locale names are now runtime Intl.DisplayNames (not copied Babel strings). Exact upstream dataset snapshot and territorial area definitions are not established. All rows marked unreviewed. Known issues include Burundi and Equatorial Guinea capital fields, ambiguous capital designations and Serbia area/coordinates. Do not use this registry as authoritative or score quizzes from it until editorial correction.
- Scope: 193 UN members plus two non-member observer states (Holy See represented by VA/Vatican geography, State of Palestine PS). https://www.un.org/en/about-us/member-states and https://www.un.org/en/about-us/non-member-states. This convention is not a claim about all disputed entities.
- CesiumJS pinned 1.127.0 via jsDelivr, Apache-2.0 upstream: https://github.com/CesiumGS/cesium. OSM tiles with credits, limited interactive prototype use only: https://operations.osmfoundation.org/policies/tiles/. No tile prefetching. A production tile provider must be assessed.
- Esri terrain optional; endpoint copied from V0.2; API documentation https://cesium.com/learn/cesiumjs/ref-doc/ArcGISTiledElevationTerrainProvider.html. Access, service terms, actual elevation and coverage not validated; no tokens published. Attribution and usage terms to verify before release.
- Wikipedia links open a user-selected search; no automatic article/image reproduction yet. Original V0.2 wiki search and Ollama server withheld pending source attribution, origin validation and security review.
- CDN and maps transmit requests to third parties. Local browser visit counts only; no analytics or cloud synchronization implemented.

- GEBCO_2025 WMS pinned layer gebco_2025, HTTPS endpoint https://wms.gebco.net/2025/mapserv? ; official documentation https://www.gebco.net/data-products/gebco-web-services/previous-wms. Official WMS 1.3.0 GetMap example returned an image during this iteration. Attribution displayed in Cesium credits. Shaded relief is a raster visualization, not a mesh or quantitative bathymetry; no nautical use. Browser CORS/tile behavior and service terms for deployment still require verification.
- Esri point sampling uses Cesium sampleTerrain at level 10, reports the camera-coordinate location only, never substitutes ellipsoid zero. Vertical datum and measured accuracy not yet validated. No claim of successful live sampling.

- 2026-11-26: UNSD M49 official geographic classification https://unstats.un.org/unsd/methodology/m49/overview/ : transcribed country-to-deepest-region factual associations for the 195 registry codes only (intermediate region where present). Statistical convention, not legal status or territorial adjudication. Region names via Intl.DisplayNames; 20 original introductory narration templates, not independently language-reviewed. Regional quiz scores only these associations, never unreviewed capital/area seeds. No extra network request for quiz or narration text; local browser speech engine may have its own network behavior.

- 2026-11-26: Natural Earth 1:50m land and disputed-area boundary lines, v5.1.2 pinned commit f1890d9f152c896d250a77557a5751a93d494776. Both raw GeoJSON files fetched and parsed during development (390 and 34 features). Public domain dataset: https://www.naturalearthdata.com/about/terms-of-use/ . De facto cartographic representation, not legal boundary or 195-state membership; disputed lines separate in orange; incomplete at this scale, no maritime limits. Browser rendering/CORS still untested.
- Optional Wikimedia Commons geosearch near the atlas camera coordinates (10 km radius, max 5 results). Uses API imageinfo extmetadata, https://www.mediawiki.org/wiki/API:Imageinfo and https://www.mediawiki.org/wiki/API:Cross-site_requests . Only JPEG/PNG, selected CC BY/BY-SA and CC0 with matching license URL, creator/attribution and Commons links; restrictions cause rejection. Metadata displayed as plain text, thumbnails not cropped, no images stored in repo. Automated license/metadata filter is not rights clearance, location or subject verification; no curated 195-country photo coverage claimed. No live browser/Commons test yet.

- 2026-11-26: guide uses only original regional narration and short M49 methodology paraphrase linked to UNSD M49. No unreviewed seed capital/area supplied. Ollama API chat structured IDs and nonstreaming response per https://docs.ollama.com/api/chat ; local-only operator setup per https://docs.ollama.com/faq . Adapter is opt-in; only fixed loopback destination, no remote fallback or model tools, no automatic downloads. Model can select irrelevant existing evidence but cannot inject new text or links. Local daemon settings and actual model quality require runtime validation. The browser still loads existing third-party map/CDN assets.

- 2026-11-26: numeric regional grid import targets GEBCO 2025 ice-surface 15 arc-second geographic data, metres, https://www.gebco.net/data-products-gridded-bathymetry-data/gebco2025-grid ; public-domain data with source attribution and safety disclaimer, DOI https://doi.org/10.5285/37c52e96-24ea-67ce-e063-7086abc05f29 . Esri ASCII format https://resources.arcgis.com/en/help/main/10.1/009t/009t0000000z000000.htm (north-first rows, cell centres/corners, nodata). No third-party grid committed; local file provenance is user-declared, not authenticated. Local metric approximation at mean latitude, no datum conversion, 2–128 cells per axis, ±85°, no antimeridian, no global terrain mesh. Source notes confirm heterogeneous vertical datum, not nautical use. Test fixtures are synthetic, not real bathymetric measurements.
